Quote and expiry settings

A new alert schedules a virtual entry at the next one-minute boundary. It uses the first option trade reported at or after that time as the candle open (for a 09:34 alert, entry is at 09:35). The option-chain LTP is used only to estimate size while waiting; the actual candle-open price must still fit your budget. No broker order is sent. Nearby OTM strikes are considered when ATM/near-ITM lots exceed the budget. Target and stop use the actual simulated entry premium. Live option quotes require Upstox connection. Prior alerts are not replayed. Entry cutoff 15:15 IST; exit cutoff 15:20 IST.

No real broker orders can be placed from this terminal.

Entries are virtual at the first option trade reported at or after the next one-minute boundary, matching replay’s next-candle open rule. If no such trade arrives within that minute, the pending entry is cancelled. No broker order is sent. Exits and marks use observed option bid quotes. These are simulated prices, not guaranteed exchange fills. A gap can cross a stop; missing live quotes leave P&L unavailable. Historical alerts receive no invented fills.
